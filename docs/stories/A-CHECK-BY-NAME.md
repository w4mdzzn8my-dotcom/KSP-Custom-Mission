# Routine scene: A check by name

**Status:** proposed routine scene using actual shared duty status when implemented
in a playable mission. No animation or completed hardware task is implied.

Hamish opens the engineering panel and selects Basil for a scheduled array
check. The current crew status refuses normal duty. They read the reason in
the crew panel and leave the array untouched while Basil takes the indicated
rest or care. Hamish can still inspect the read-only measurements.

“Keep my name on the check,” Basil says.

“Held for a fresh review,” Hamish replies.

When actual crew state becomes eligible again, they check Basil by name and
review the device state before requesting the ordinary operation. The task does
not switch itself to a frozen relief crewmember, erase an injury or infer that
a meal alone completed recovery.

This is routine cooperative care. It introduces no extra emergency, forced
thaw, substitute identity, automatic command or burn clearance.
